# 前端词典

把前端术语，讲明白。

前端词典是一个中文前端术语知识库，计划用简洁的解释、贴近实际的例子和相关概念，帮助开发者理解日常开发中遇到的名词与缩写。

## 内容方向

- HTML、CSS 与 JavaScript 基础概念
- 浏览器、网络与 Web 标准
- 框架、组件与状态管理
- 工程化、测试与性能优化

## 词条结构

计划为每个词条提供：

- 名称：中文名、英文名及常见缩写
- 解释：这个概念是什么，解决什么问题
- 示例：在实际开发中如何使用
- 关联：容易混淆或值得一起了解的概念
- 参考：官方文档或标准链接
