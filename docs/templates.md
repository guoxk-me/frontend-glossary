# Templates 使用与维护

## 首版范围

入口为 `/templates`，英文入口为 `/en/templates`。当前正式案例只有“简洁浅色客户管理”，当前列表不展示类型筛选与独立搜索，使用全局搜索查找案例。

用户可以查看整体参考、勾选区域、填写调整要求，直接复制需求。区域默认采用完整样式，布局/配色/字体/装饰/状态与动效开关收进“详细调整”。需要复用时再保存到新方案或已有方案。界面语言直接切换，不改写方案；界面语言和需求输出语言分开，新方案默认英文，自定义文字保持原文。

列表与详情中的图片用于概览；客户管理模板的全屏入口是可操作页面，支持搜索、状态与负责人筛选、分页、客户详情、新增客户、状态更新和侧栏切换。演示数据在本次全屏预览内有效，重置或关闭后恢复，不写入方案或真实业务系统。需求调整仍只修改描述，不会实时重绘演示。

## 保存与保护

- 选取草稿在本次应用浏览期间保留；刷新前需要加入方案，才有持久保存保证。
- 方案保存所选区域的双语文字、保留特征、自定义调整、区域关系和来源快照。后续更新模板内容不自动改写已存方案。
- 加入已有方案时保留原内容。重复区域需要明确选择保留或替换，不再提供再次追加，预览随选择变化。
- 更新或移除已有参考时，手写正文继续保留并标记待更新；重新生成和输出语言替换继续先预览、确认。
- 追加后超出正文或备份限制时拒绝本次变更，保留原方案。
- 模板收藏与词条收藏分别保存。JSON 备份同时包含模板收藏和参考；继续使用原有本地存储键和版本 1，通过可选字段读取旧备份。
- 新备份需要使用支持 Templates 的版本导入；不承诺旧版应用能读取新增字段。

## 新增案例

1. 保存来源、截图或录屏，以及“希望复用什么”。首版缩略图使用 PNG，放在 `public/templates/`，以纳入现有离线缓存。
2. 在 `content/templates/` 增加一个 JSON 文件，可参考 `customer-management.json`。
3. 填写稳定的 `slug`、中英文名称、双语说明、类型 `page/website`、场景 `admin`、来源 `original/reference`、原始链接与搜索关键词。
4. 在 `pages` 中按页面记录 `id`、双语标题、缩略图和大图路径；整站案例可以有多页，但当前首个案例只验证单页流程。
5. 在每页 `regions` 中填写区域编号、双语名称、位置关系、相邻区域编号、已有词条 slug，以及可确认的视觉特征。
6. 每项视觉特征使用 `layout/palette/typography/decoration/states` 中的一类，并提供中英文描述。不要把不可确认的行为写成事实。
7. 审阅“选择区域 → 调整特征 → 描述预览 → 加入方案”的结果，并执行 `pnpm check` 后发布。

现有内容模式与校验规则位于 `app/lib/template-schema.ts`。描述选择与生成规则位于 `app/lib/templates.ts`。词条关联应指向真实已有内容，关联本身不会自动把整个词条的要求加入模板方案。

## 离线与预览

详情页“全屏预览”铺满浏览器窗口并渲染可操作演示。顶部可重置演示或关闭；客户详情抽屉与新增表单关闭后返回演示，退出全屏后回到原来的选择位置。

文字、区域拆解、方案整理与缩略图纳入离线范围。离线就绪检查覆盖中英文模板页、负载、模板内容库与缩略图；资源缺失时不报告已就绪。

离线刷新后，网络状态在首次挂载后应用，避免服务端默认在线状态让大图按钮保留错误的可用外观。高清图和外部预览入口按联网能力使用。

页面配置可选 `demo: "customer-management"`，仅为有对应演示实现的页面启用交互入口。未提供 demo 的模板仍显示“查看图片”，不伪装成交互页面。本站演示随 PWA 资源缓存，可在离线就绪后使用；外部预览仍需联网。

## 本地验证

执行 `pnpm check`，依次进行 Lint、类型检查、规则与 Nuxt 组件测试、静态构建。

测试覆盖取消视觉特征、双语描述、自定义文字保留、来源快照、旧备份与新备份往返、重复处理、手写保护、长度限制及缺失模板缓存。

浏览器检查仍需覆盖实际页面、手机与平板宽度、双语、离线硬刷新。静态构建和视口模拟不能代替真机安装或屏幕阅读器验收。
